# 功能狀態

狀態只有三種：規劃中、進行中、通過。「通過」代表該項目的自動化測試已在 Windows CI 上通過；沒有自動化測試涵蓋的部分會另外註明。

最近一次驗證：commit `8184fac`，GitHub Actions run 43653659694（Windows）。

| 功能 | 階段 | 狀態 | 依據 |
| --- | --- | --- | --- |
| 專案骨架與 Windows CI | 1 | 通過 | CI 全部步驟成功 |
| C++ 引擎解碼 JPEG、PNG（含縮小、損毀檔案、無效參數） | 1 | 通過 | CTest 1 項、Rust 5 項測試 |
| Rust 核心開檔（中文路徑、損毀檔、空檔、找不到檔案、原始檔不被修改） | 1 | 通過 | Rust 7 項測試 |
| 介面的畫面解析與雙語字串表 | 1 | 通過 | Vitest 7 項測試 |
| 未簽章 Windows 安裝程式（CI 產出） | 1 | 通過（僅確認產出） | CI 產出 `AI Beauty Studio_0.1.0_x64-setup.exe`；尚未在乾淨機器上安裝測試 |
| 在應用程式視窗中開啟並顯示影像 | 1 | 進行中 | 各層都有測試，但整個視窗流程尚無自動化測試，需人工確認 |
| TIFF、WebP 解碼 | 1 | 進行中 | 已編入引擎，尚無測試影像 |
| 相依套件授權清冊 | 1 | 進行中 | lockfile 已產生，尚未逐列核對 |
| 模型候選清單與授權紀錄 | 1 | 規劃中 | |
